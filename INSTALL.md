# Установка — шаг за шагом

Для тех, кто хочет просто повторить команды по порядку, без чтения всего README.

> ⚠️ Честно: `netctl install` проверен по частям (генерация конфигов, установка пакетов,
> синтаксис), но ни разу не гонялся целиком на свежепрошитом «чистом» роутере с нуля.
> Слабые места — установка zapret, переключение dnsmasq→dnsmasq-full (DNS на секунду
> пропадает), имена пакетов apk/opkg на конкретной версии прошивки. После установки
> **обязательно** прогони `netctl doctor` (шаг 6) — сразу покажет, что не так.

## 0. Что нужно до начала

- Роутер уже на **OpenWrt** (прошит), с рабочим WAN-интернетом.
- Комп с `ssh` — Linux/macOS есть из коробки, Windows 10/11 тоже (не нужен putty).
- Свои **VLESS-Reality ноды** (ссылки `vless://…` — обычно даёт провайдер прокси через
  «Поделиться» в приложении типа Happ). Без нод кит поставит только zapret (обход DPI),
  прокси-часть можно выключить — см. шаг 3.

## 1. Забросить SSH-ключ на роутер

Чтобы `netctl` заходил без пароля каждый раз.

```sh
ssh-copy-id root@192.168.1.1        # IP роутера — обычно 192.168.1.1, смотри в LuCI
```

Если ругается / нет `ssh-copy-id` (частый случай на дефолтном dropbear-роутере) —
вручную:

```sh
cat ~/.ssh/id_ed25519.pub | ssh root@192.168.1.1 "cat >> /etc/dropbear/authorized_keys"
```

Или через веб-морду: LuCI → **System → Administration → SSH-Keys** → вставить публичный
ключ (`cat ~/.ssh/id_ed25519.pub`) → Save.

Проверка — должно зайти БЕЗ пароля:
```sh
ssh root@192.168.1.1 echo ok
```

## 2. Скачать кит

```sh
git clone https://github.com/pepetutu1337/openwrt-bypass-kit.git
cd openwrt-bypass-kit
```

(или просто скачай ZIP с GitHub и распакуй, если без git)

## 3. Заполнить конфиг под себя

```sh
nano config/kit.conf         # ROUTER_IP, если не 192.168.1.1
cp config/nodes.list.example config/nodes.list
nano config/nodes.list       # вставь свои vless://-ссылки, по одной на строку
```

Нет своих нод — просто оставь `config/nodes.list` пустым и в `config/kit.conf` поставь
`PROXY_ENABLE="0"`: поставится только zapret (обход DPI), без прокси-части.

Домены, которые пойдут через ноду (заблокированные/гео-ограниченные сайты), уже в
`config/domains.list` — список приличный из коробки, дописать свои можно потом одной
командой (шаг 7).

## 4. Установка

```sh
./bin/netctl install
```

На Windows: `bin\netctl.cmd install`

Это займёт пару минут — поставит пакеты (`sing-box`, `dnsmasq-full`, `https-dns-proxy`,
`curl`), скачает zapret, сгенерит конфиги, включит автозапуск. **DNS на роутере на
секунду мигнёт** (замена dnsmasq на dnsmasq-full) — это ожидаемо, не баг.

Если `install` упал на середине — почини, что написано в ошибке, и просто запусти
`./bin/netctl install` снова: команда идемпотентна (безопасно повторять).

## 5. Проверка

```sh
./bin/netctl status
./bin/netctl doctor
```

`status` — что запущено. `doctor` — прогоняет тест-домен по всей цепочке (DNS → набор
proxy4 → выходной IP → страна → QUIC) и явно показывает, где именно разрыв, если что-то
не так.

## 6. (опционально) Графическая панель вместо терминала

```sh
bin/netgui-web           # Linux/macOS
bin\netgui-web.cmd       # Windows
```

Откроет браузер с тёмной панелью — те же команды кнопками, живой вывод, мастер
добавления нод из буфера обмена. Нужен только Python 3 (на Windows — с python.org).

## Если что-то не так

1. `netctl doctor` — почти всегда сразу показывает, на каком звене обрыв.
2. Тестируй с **другого устройства** в сети роутера, не с самого роутера и не с компа,
   если на нём тоже включён VPN — он перехватит трафик раньше, чем тот дойдёт до роутера.
3. `netctl logs sing-box` / `zapret` / `dns` — сырые логи служб.
4. Раздел «Тонкости и грабли» в [README.md](README.md) — там частые проблемы
   (Cloudflare 403 у голого curl, zapret под конкретного провайдера, РФ-сайты и split-DNS).
