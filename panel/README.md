# panel — веб-панель твоего живого роутера

Это **не** установка кита (см. корень репо). Кит ставит обход с нуля на чистый OpenWrt.
А эта панель управляет **уже настроенным вручную** роутером AX3000T: sing-box redirect,
uci-ipset `proxy4/6`, `https-dns-proxy` (:5053/:5054), zapret в `/opt/zapret`,
`geoblock-update` + `proxy-watchdog`, split-ru, clash API :9090.

Панель живёт в двух видах. **На роутере** — чтобы работала, когда Дека нет дома
(родители, телефон, любое устройство в домашней сети). **На Деке** — старый вариант
с python-сервером и SSH, со всеми продвинутыми штуками (добавление нод из vless/JSON,
ротация подписки, бэкапы).

## На роутере (рекомендуется)

```sh
cd ~/Dev/openwrt-bypass-kit/panel
./router/install.sh                          # без пароля, только домашняя сеть
./router/install.sh --pass СЕКРЕТ            # с паролем на вход
./router/install.sh --bot-token T --bot-allow "12345"   # ещё и Telegram-бот
./router/install.sh --uninstall              # снести
```

Ставит на роутер: `rctl` в `/usr/sbin`, статику в `/www/panel`, CGI-бэкенд под
отдельным инстансом `uhttpd` на порту 8080. **Слушает только LAN-адрес роутера**,
наружу не торчит. Python не нужен — всё на busybox sh. Заодно прописывает крон
`*/15 * * * * rctl fix` (сам поднимает упавшее и уводит с мёртвой ноды).

Адрес: `http://192.168.1.1:8080/`. Первый экран — светофор и две большие кнопки
(«Починить», «Проверить ютуб»), остальное спрятано за «Подробности». Это чтобы
человек, который не в теме, мог починить сам.

## Telegram-бот

`/usr/sbin/rctl-bot` + сервис `/etc/init.d/rctl-bot`, настройки в `/etc/rctl-bot.conf`
(права 600). Только исходящие соединения — никаких пробросов портов. В API ходит через
локальный SOCKS sing-box (`127.0.0.1:1180`), потому что напрямую с роутера
`api.telegram.org` не открывается. Команды выполняет только для `BOT_ALLOW`; чужому
чату отвечает его же `chat_id` и больше ничего.

Кнопки: Статус, Починить, Ютуб, Серверы. Плюс `/use ИМЯ`, `/best`, `/auto`, `/logs`.

## На Деке

```sh
~/Dev/openwrt-bypass-kit/panel/run   # поднимет локальный сервер и откроет браузер
```

Нужен `python3` (на SteamOS есть) + `ssh`. Панель слушает только `127.0.0.1` под
секретным токеном. На Linux при первом запуске создаётся ярлык «Панель роутера» в меню.

> ⚠️ Панель ходит по SSH к **реальному** роутеру. Перед работой убедись, что Дек на
> Wi-Fi `kv_52`, а не на роутере Ростелекома с тем же именем. Ключ должен быть заброшен
> на роутер (вход без пароля).

## Что умеет

- **Статус** — сервисы (sing-box/zapret/DoH/dnsmasq), активная нода (clash API),
  число проксируемых доменов, счётчик QUIC-блока.
- **Чекап** — полный прогон: сервисы (sing-box/zapret/dnsmasq/DoH) → DNS через DoH → в наборах
  proxy4/6? → активная нода → QUIC → split-RU (РФ-сайты) → IPv6-утечка → домены → geoblock →
  telegram-cidr → WAN → краны.
- **Ноды** — список авто-пула и активная, тест задержек, закрепить по имени (`pl`, `de1`…),
  вернуть авто-выбор. Кириллические теги — в clash-дашборде.
- **Домены** — список / добавить / убрать (реальный uci-ipset flow + чистый DoH-резолв,
  перезапуск dnsmasq).
- **Сервисы** — перезапуск sing-box / zapret / dnsmasq / https-dns-proxy.
- **Спец** — geoblock обновить/счёт, QUIC-блок вкл/выкл, прогнать сторож нод.
- **Telegram CIDR + бэкап** — счёт/обновление офиц. CIDR Telegram (core.telegram.org,
  только аддитивно — новый диапазон идёт отдельным `21-telegram-cidr-extra.nft`, базовый
  файл не трогается), бэкап конфигов перед прошивкой (`sysupgrade -b`, тянется в `panel/backups/`).
- **Логи** — sing-box / zapret / dnsmasq (`logread`).

## Файлы

```
panel.conf          ← IP/юзер/порт роутера, clash API, тест-домен
rctl                ← движок. Работает в двух режимах: на роутере локально,
                      с Дека — по SSH с мультиплексированием (ControlMaster)
run                 ← лаунчер версии для Дека
web/server.py       ← локальный сервер (Python stdlib, allowlist + SSE-стрим)
web/index.html      ← панель для Дека
router/install.sh   ← установка на роутер (панель + бот + крон), она же удалялка
router/index.html   ← панель для роутера (светофор + режим «Починить»)
router/api          ← CGI-бэкенд под uhttpd, строгий список разрешённых действий
router/rctl-bot     ← Telegram-бот
router/rctl-bot.init← procd-сервис бота
```

Всё доступно и из терминала: `rctl status`, `rctl fix`, `rctl yttest`,
`rctl nodes best`, `rctl domains add figma.com` (`rctl help`).

## Полезное знание про гугл

`geoblock`-список нельзя пускать в прокси целиком. Гугл раздаёт своим сервисам
адреса из общих `/24`, поэтому `news.google.com` в наборе `proxy4` рано или поздно
утаскивает туда же ютуб — и видео перестаёт стартовать, потому что гугл видит
датацентровый адрес ноды и требует бот-проверку. Гугловые домены отсеиваются
через `/etc/geoblock-exclude.txt`, и `geoblock-update` уважает этот файл.

## Статус

Проверено против живого роутера: панель на роутере (страница, API, валидация
входа, светофор из живых данных), `rctl` в обоих режимах, `fix`, `yttest`,
`nodes best`, geoblock-фильтр. Бот залит и синтаксически проверен, разбор ответов
Telegram протестирован на образцах — **живьём не гонялся, нужен токен**.
