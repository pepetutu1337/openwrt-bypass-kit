# panel — веб-панель твоего живого роутера

Это **не** установка кита (см. корень репо). Кит ставит обход с нуля на чистый OpenWrt.
А эта панель управляет **уже настроенным вручную** роутером AX3000T: sing-box redirect,
uci-ipset `proxy4/6`, `https-dns-proxy` (:5053/:5054), zapret в `/opt/zapret`,
`geoblock-update` + `proxy-watchdog`, split-ru, clash API :9090.

## Запуск

```sh
~/openwrt-bypass-kit/panel/run   # поднимет локальный сервер и откроет браузер
```

Нужен `python3` (на SteamOS есть) + `ssh`. Панель слушает только `127.0.0.1` под
секретным токеном. На Linux при первом запуске создаётся ярлык «Панель роутера» в меню.

> ⚠️ Панель ходит по SSH к **реальному** роутеру. Перед работой убедись, что Дек на
> Wi-Fi `kv_52`, а не на роутере Ростелекома с тем же именем. Ключ должен быть заброшен
> на роутер (вход без пароля).

## Что умеет

- **Статус** — сервисы (sing-box/zapret/DoH/dnsmasq), активная нода (clash API),
  число проксируемых доменов, счётчик QUIC-блока.
- **Чекап** — DNS через DoH → в наборе proxy4? → активная нода → QUIC → краны.
- **Ноды** — список авто-пула и активная, тест задержек, закрепить по имени (`pl`, `de1`…),
  вернуть авто-выбор. Кириллические теги — в clash-дашборде.
- **Домены** — список / добавить / убрать (реальный uci-ipset flow + чистый DoH-резолв,
  перезапуск dnsmasq).
- **Сервисы** — перезапуск sing-box / zapret / dnsmasq / https-dns-proxy.
- **Спец** — geoblock обновить/счёт, QUIC-блок вкл/выкл, прогнать сторож нод.
- **Логи** — sing-box / zapret / dnsmasq (`logread`).

## Файлы

```
panel.conf        ← IP/юзер/порт роутера, clash API, тест-домен
rctl              ← SSH-движок: реальные команды под этот роутер (правь тут, если пути другие)
run               ← лаунчер
web/server.py     ← локальный сервер (Python stdlib, allowlist + SSE-стрим)
web/index.html    ← сама панель
```

Всё в терминале доступно и напрямую: `./rctl status`, `./rctl nodes list`,
`./rctl domains add figma.com`, `./rctl restart sing-box` и т.д. (`./rctl help`).

## Статус

UI и сервер протестированы локально (токен, allowlist, SSE, скриншоты). Команды `rctl`
собраны по факту твоего сетапа, но **против живого роутера ещё не гонялись** — первый
реальный прогон делаем вместе, скорректируем парсинг под точный вывод busybox, если надо.
