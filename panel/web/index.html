Готово к работе 
Нажми «Статус». Панель ходит по SSH к твоему живому роутеру и показывает реальное состояние.

Добавить сервер

Вставь ссылку vless://… или весь JSON-конфиг из Happ («Поделиться» / экспорт). Можно несколько. Нода впишется в config.json роутера — с бэкапом, проверкой sing-box check и авто-откатом.

Ротация подписки

Обновил подписку в Happ и всё отвалилось? gazvpn при ротации меняет только uuid — сервера и ключи остаются. Вставь любую новую vless://…-ссылку или JSON из Happ: uuid перепишется в нодах этой подписки (с бэкапом и проверкой). Если в конфиге живут ноды нескольких подписок — вставляй именно ссылку/JSON (по адресу сервера панель поймёт, чьи ноды ротировать); голый uuid годится, только пока подписка одна. Если сменились и адреса серверов — добавь их через «Добавить сервер».

Подключение к роутеру

Куда ходить по SSH. Ключ уже должен быть заброшен на роутер (вход без пароля).

Панель управляет реальным роутером. Убедись, что Дек на Wi-Fi kv_52 (а не на роутере Ростелекома с тем же именем).
